# TætPåNaturen

## Projektets formål
TætPåNaturen er en statisk hjemmeside, der hjælper begyndere med at komme i gang med yoga i naturen.

## Teknologier
- HTML
- CSS
- Figma
- Figma MCP
- Git/GitHub

## Udvalgt side
I denne opgave skal der kun arbejdes med Forsiden.

De øvrige sider skal ikke implementeres.

## Figma
Figma er source of truth for designet.

Codex skal bruge Figma MCP som opslagsværk for:
- layout
- komponenter
- farver
- typografi
- spacing
- billeder
- knapper
- responsive forskelle

## Design
Farver:
- Warm Cream: #F2EDE3
- Deep Forest Green: #30483A
- Sage Green: #A8B5A2
- Sort: #000000
- Hvid: #FFFFFF

Typografi:
- Cormorant Garamond til logo og større overskrifter
- Roboto Serif til øvrige overskrifter og brødtekst

Designet bygger på enkelhed, lighed og nærhed.

## Struktur
Brug semantisk HTML, hvor det er relevant:
- header
- nav
- main
- section
- article
- footer

Brug tydelige og meningsfulde klassenavne.

## Responsivitet
Forsiden skal fungere på både desktop og mobil.

Desktop og mobil skal følge Figma-designet.

## Begrænsninger
Dette er en statisk hjemmeside.

Brug ikke:
- database
- login
- brugerprofiler
- backend
- betalingssystem
- eksterne API'er

## Tilgængelighed
- Brug semantisk HTML.
- Brug relevante alt-tekster.
- Links og knapper skal være tydelige.
- Indholdet skal være læsbart.

## Arbejdsprincip
Arbejd kun med Forsiden.

Implementér ikke de øvrige sider.

Sammenlign implementationen med Figma efter kodning og ret tydelige fejl og mangler.
